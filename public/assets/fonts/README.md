# Local typefaces

- Be Vietnam Pro: UI, dialogue, controls and hub canvas labels; weights 400,600,700,800.
- Lora: headings; original variable weight range 400–700.

Both original font families declare Vietnamese coverage in Google Fonts metadata. The unmodified TTFs were downloaded from https://github.com/google/fonts/tree/main/ofl/bevietnampro and https://github.com/google/fonts/tree/main/ofl/lora on 2026-10-26. Their complete SIL Open Font License 1.1 notices are bundled alongside the files. No remote font service is used at runtime.
