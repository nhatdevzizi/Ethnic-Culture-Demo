# Tech stack

## Engine / runtime
- Engine: Phaser 4.2.1, exact dependency.
- Language: TypeScript with strict checking.
- Target: desktop browser, 1280×720 virtual canvas, FIT/AUTO_CENTER. The 2560×1920 hub uses zoom 1.25 and a dynamic HUD reserve of at least 96 logical pixels. It shows 1024 world pixels horizontally; actual height depends on the HUD/window. Other scenes retain the full logical canvas.

## Libraries / frameworks
Phaser owns scene graphics, animation, cameras, and Arcade Physics. Vite builds local static files. Vitest tests pure logic. Playwright tests browser controls and captures screenshots. No React.

## Tooling
npm and lockfile; `npm run dev`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`. Release content gate uses `npm run build:release`. Original small generated textures need no Git LFS. Be Vietnam Pro (UI/canvas, weights 400/600/700/800) and Lora (headings, variable 400–700) are local TTF assets with bundled OFL licenses. Startup waits for font metrics before creating the Phaser game; a failed font still permits the fallback stack to play.

## Project layout
HubLandscape generates winding station roads and theme-specific vegetation from a seed (URL `seed`, default 42). Scenery-layout JSON authors house-side props, ponds, bridge corridors, clearings and shore paths. Those areas reserve space before plant placement. All visible image art uses supplied PNGs; Preload creates 32px repeatable terrain textures from supplied sheet frames. Generated SVG sprites/tiles and animals are not loaded. The supplied player uses an unchanged 22×18 world-pixel collision footprint with a Low-motion-aware walking sway. HubLayout combines all scenery footprints with house/guide/plaza collisions; physics and return-position validation use the same result. Pond collisions leave a walkable bridge gap. Deterministic regeneration preserves the world on return, without a second world-state store. SessionStore validates positions against map dimensions and safely migrates older layout positions while retaining stamps. The DOM/SVG route map reads the same roads. Browser station labels track the camera; scene shutdown removes their nodes and render listener.

`src/game/scenes` owns disposable scene state. `src/game/minigames` owns scene adapters. `src/game/core` owns types, registry, puzzle rules, validation, and saved progress. `src/game/ui` owns DOM overlays. `src/content` and `src/i18n` own text/data. `tests` owns unit/browser checks. `docs` owns design and status.

## Conventions
PascalCase classes; camelCase functions; stable asset keys. Input has one DOM-aware action boundary. Scene shutdown clears input, camera resize observers, and scene handlers. Pause blocks world motion and activity actions; hidden pages/window blur open pause and reset held keys. M02 rhythm advances only from scene update while unblocked, with normal/slow/untimed pure rules; no global timers or sound loops. M03 keeps evidence in StoryPractice. GameEvents validates the complete handoff before SessionStore.applyResult(result, returnPosition) makes one save, then starts the destination scene. Save schema/content version remain unchanged; loaded statuses, stamps, and learned facts must agree. URL mode/locale override loaded preferences. Debug text/time hooks and paused-scene observations exist only in development.

AccessibilityPreferences stores an explicit low-motion override separately from session progress and defaults to the OS preference. OverlayController owns localized controls and fatal recovery; main pauses active scenes through its single error callback. AudioManager's unavailable callback updates open captions immediately. The build uses pure validateContentBundle for all content collections; runtime facts remain labeled fictional until reviewed. Playwright development/production artifacts use separate folders. See PHASE_4_QA.md for the one headless visibility skip and the limits of CPU-throttled observations.

## Out-of-scope dependencies
No server, network APIs, UI framework, remote fonts, analytics, or audio libraries. AudioManager uses browser media elements and local original PCM WAV files with attribution metadata. Original pixel SVG/WAV assets are reproducible with `node scripts/generate-media.mjs`. PresentationRoute reads the registry; TutorialProgress stores dismissal separately without changing the progress schema. HubLayout shares authored collision rectangles between physics and saved-position recovery; blocked old positions fall back to the existing map spawn while SessionStore retains progress. Map JSON owns roads and landscape placement; station portals remain in the registry. Development snapshots include camera/label geometry for visual checks; production globals remain absent.

Natural-world refinement: world-trails.json now owns grid-aligned route points, a northern link, per-theme road styles, house frame choices and grove centers. HubLandscape rasterizes connected roads into supplied sheet frames and reserves every route before placing vegetation. The main lake's row mask is converted by waterRects into the same rectangles for drawing and collision; invalid masks fail visibly. The map guide includes the northern link and masked lake. Scene flow, result contracts and progress ownership stay unchanged. Southern entrances moved 32 pixels to align their approaches to the 64-pixel road grid.
