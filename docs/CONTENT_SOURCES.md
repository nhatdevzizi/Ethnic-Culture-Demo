# Content review and sources

All current learning material is fictional, non-cultural prototype content. It must display DEMO / UNVERIFIED CONTENT even in a production demo bundle. No community records, greetings, rituals, authentic patterns, recordings, or factual cultural claims are supplied.

For publication: research a directly relevant primary source, record community/place/time/qualifiers, check media permission, ask a qualified reviewer, then set approved with the reviewer name. Do not use technical references as cultural sources. Unverified or disputed material stays unpublished.

Each fact has id, communityIds, localized title/body, sourceUrls, reviewStatus, and optional context/reviewer/permittedAssetIds. Real claims require sources. Release mode requires approved, sourced selected facts. Demo content remains draft; do not mark it approved to bypass validation.

Community records include id, displayName, alternateNames, description, places, sourceUrls, and reviewStatus. Assets include stable id/path, creator, license, attribution, allowedUse, and reviewStatus. The sources/credits overlay reads these records.
