# Guided demo presentation

This is a fictional mechanics demo. It is not approved cultural teaching material. All three activities remain visibly labeled DEMO / UNVERIFIED CONTENT. Qualified content review and a real laptop/projector check remain required.

See [PRESENTER_TROUBLESHOOTING.md](PRESENTER_TROUBLESHOOTING.md) for Phase 4 recovery steps and the physical acceptance checklist.

## Before presenting
1. Run `npm run build`, then `npm run preview`.
2. Open http://127.0.0.1:4281/?mode=presentation&lang=vi . Keep the complete dist folder on the local server.
3. Choose Start for a fresh passport. Continue preserves prior activity results. Tutorial dismissal is a separate browser preference; reopen it from Presenter.
4. Check fullscreen, text, speaker volume, and keyboard focus on the actual display. Sound starts muted; enable it in Pause or Presenter if wanted. All activities also work with captions and visual cues.

## Speaking plan
These are suggested speaking durations, not measured run times or enforced timers.

| Segment | Suggested time | Presenter action |
|---|---|---|
| Welcome and premise | 30 seconds | Explain the fictional exhibition and participation stamps. |
| Hub and guide | 45 seconds | Show walking, E/Space, the first-run hint, and the next-station direction. |
| Pattern Studio | 60 seconds | Read the note, arrange plan → cut → assemble, and collect the stamp. |
| Sound Garden | 60 seconds | Show hit/rest captions; choose slow or untimed; complete the six-step pattern. |
| Story Trail | 75 seconds | Ask all three fictional helpers, collect evidence, and choose a plan using their individual requests. |
| Review and discussion | 60 seconds | Open the ending, read the three cards, show Sources & credits, and ask the discussion question. |

Total suggested time: 5 minutes 30 seconds. Allow audience questions or retries to extend this to 5–7 minutes. Do not present this target as a completed projector rehearsal.

## Controls during the talk
- Use the garden paths or choose Presenter → Go to next activity. Travel reaches a safe entrance; interact there to enter normally.
- Use N to skip a station in guided mode. A skip stays skipped and earns no stamp; the route still advances.
- Use P/Esc or the pause button for a break. Menus stop play. A hidden page or lost window focus pauses; resume explicitly.
- Use R or the clickable Restart action to restart an attempt. Existing stamps remain saved.
- Use M or the sound button to mute. Volume is available in Pause and Presenter.
- Enable Low motion in Pause or Presenter when needed. It defaults to the OS preference; an explicit choice persists separately from the passport.
- Use Finish at any point. Unvisited, skipped, and completed cards remain distinct; only recorded facts appear as practiced.
- Return to the hub from the ending to continue. Open Sources & credits for original-media notices, font licenses, and fact review status.

## Recovery
Missing optional audio leaves the visual/captioned game playable. A critical map/image failure shows a reload action; check that all build files are served locally. Source links need internet only when opened. Browser fullscreen and actual audio output depend on the presentation device; verify those before the talk.
